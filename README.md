## 📖 Sobre o projeto

O **Go-Virado-No-Gopher** é um repositório de estudos práticos da linguagem Go (Golang), inspirado na organização didática do [Java-Virado-No-Jiraya](https://github.com/Sc4rlxrd/Java-Virado-No-Jiraya).

A proposta é aprender Go de forma progressiva, combinando teoria, exemplos executáveis, exercícios e projetos práticos, respeitando as características e boas práticas da linguagem.

O foco é desenvolver uma base sólida para trabalhar com **Backend, ferramentas CLI, automação Linux, containers, Kubernetes e infraestrutura cloud**.

## 🎯 Objetivos

- 📚 Aprender Go do básico ao avançado.
- 🧠 Compreender os conceitos e o estilo idiomático da linguagem.
- ☕ Comparar Go com Java quando isso facilitar o aprendizado.
- 🔌 Desenvolver APIs REST e serviços backend.
- 🧪 Escrever testes automatizados e código confiável.
- ⚙️ Criar ferramentas CLI e automações para Linux.
- 🐳 Aplicar Go em Docker, Kubernetes e CI/CD.
- ☁️ Explorar ferramentas de infraestrutura e cloud.

## ⚡ Como executar os exemplos

### Pré-requisitos

- [Go](https://go.dev/dl/) instalado.
- Git instalado.
- Terminal Linux ou ambiente compatível.

Confira a instalação:

```bash
go version
git --version
```

### Executar uma aula

Entre no diretório do exemplo desejado e execute:

```bash
cd 01_fundamentos/01_variaveis_tipos
go run .
```

Cada exemplo executável deve estar organizado em um pacote Go válido, com seu próprio ponto de entrada quando necessário.

### Compilar um programa

```bash
go build .
```

### Formatar o código

```bash
gofmt -w .
```

### Executar os testes

Na raiz do módulo:

```bash
go test ./...
```

### Verificar possíveis problemas

```bash
go vet ./...
```

| Etapa | Conteúdo |

| 01 — Fundamentos | Sintaxe, variáveis, tipos, operadores e estruturas de controle |

| 03 — Qualidade e concorrência | Testes, organização de pacotes, goroutines e channels |
| 04 — Backend | HTTP, APIs REST, JSON, bancos de dados e autenticação |
| 05 — DevOps | CLI, automação Linux, Docker, Kubernetes, CI/CD e cloud |
| 06 — Aprofundamento | Profiling, benchmarks, fuzzing, segurança e distribuição de aplicações |
